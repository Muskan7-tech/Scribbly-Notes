# Scribbly Notes

Scribbly Notes is a small, offline web app for writing notes and previewing them on notebook-style pages.

## Files

- `index.html` — the app page and note editor.
- `style.css` — the layout and notebook styling.
- `script.js` — the live preview, 24-line page layout, and PNG export.
- `prompts.md` — project scope and implementation notes.

## Run it

Open `index.html` in a current web browser. The note editor and PNG export work locally without an account or API. Type a note, use the page controls to review it, then choose **Export PNG** to save a tall image with all notebook pages and page numbers.

The handwriting look uses fonts installed on the device, so the exact appearance may vary slightly between computers.
